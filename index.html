🏡 住宿與泡湯

已納入行程

恆春住宿區（私人住宿）

訂房平台常見入住時間為 15:00 後、退房 11:00 前；實際仍以你的訂房確認單為準。

私人住宿的停車與入住資訊請以個人訂房確認單為準。

茴香戀戀溫泉會館｜四重溪裸湯

第一天晚餐後先買嚕嚕咪炸物，再前往泡湯。官方介紹有半露天景觀裸湯；園區公開營業時間為 08:00–22:00。

裸湯最後入場、當日開放狀況、男女湯規範與是否需預約，請以當日電話確認：08-882-4900。

🔎 行程檢查結果

全部綠燈

綠燈 第一天路線只呈現車城、恆春、四重溪，不混入第二天枋寮行程。

綠燈 第二天返程另列：恆春 → 半島植蕨 → 枋寮阿東火鍋 → 高雄。

綠燈 第一天順序一致：午餐 → 看海美術館 → 福安宮 → 正黃家綠豆蒜與皮蛋 → 半啅 → 入住與晚餐 → 嚕嚕咪 → 泡湯。

綠燈 第二天順序一致：早餐 → 古城散步 → 退房 → 午餐 → 半島植蕨 → 18:00 返程 → 枋寮晚餐 → 高雄。

綠燈 美術館排在週一；未把週二休館日安排進第二天。

綠燈 福安宮只排第一天；沒有安排第二天回車城折返。

綠燈 泡湯前先買嚕嚕咪炸物；泡湯後返回恆春住宿。

綠燈 枋寮阿東火鍋列為第二天返程晚餐，未混入第一天路線圖。

綠燈 住宿私人資訊未公開；停車確認改為出發前待辦，不預設已完成。
